🛠️ 我的项目

RSSForge ⭐3

用 GitHub Actions 免费生成 RSS 订阅源。零成本、零服务器，fork 一下改几行配置就能跑，解决”喜欢的网站没有 RSS”的老大难。

bzuu-ima-importer

自动抓取学校官网通知公告，批量导入腾讯 ima 知识库。爬虫 + 自动化，再也不用手动刷教务网站。

wy-media-crawler

网易文创内容抓取工具，支持批量采集并导入知识库。和上面那个是同一套思路的延伸。

web-showcase

Three.js + GSAP 打造的前端动效展示页。3D 场景、滚动动画、交互效果，一个页面全塞进去。

nhor4-exam-prep

英语备考游戏化系统。把背单词、刷题做成闯关游戏，自己出题自己玩，学习不再那么痛苦。

obsidian-vault-public

我的 Obsidian 公开笔记库，PARA 结构管理。这个博客的很多文章就诞生于此。

🏠 自建服务

我用一台云服务器跑了一整套自托管服务：影视、音乐、AI 智能体、导航面板，统一入口管理。详情见 👉 自建服务导航面板上线

看得见的过程，比说得出口的形容词更有说服力。
