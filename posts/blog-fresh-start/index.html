博客搬新家了：为什么重新开始，以及我想坚持写下去的理由

这是一篇关于”博客搬家”的记录，也是一篇关于”为什么写博客”的自白。

博客搬新家了

如果你之前关注过我的小站，可能发现原来的地址（gitfox-enter.github.io）变了样——那里现在是一个个人导航页，而博客搬到了这里：Jun’s Log。

原来的博客还在，只是搬到了 gitfox-enter.github.io/gwitter/。那是一个非常简陋的”微博客”，用 GitHub Issues 当数据库，页面只有一个简单的时间线。

其实去年就开始写了

说起来，写博客这件事我不是第一次尝试。

早在去年，我就搭了一个简易的博客。那时候的想法很朴素：把一些想法记下来，把自己折腾过的东西写下来。陆陆续续写了几篇，有的是折腾记录，有的是随手感想，有的甚至就是一张图、几句话。

后来为什么停了？

没有清晰的目标，也没有好用的工具。写作流程太粗糙了——每次发布都要手动改代码、推仓库，写完一篇文章的热情，一半耗在折腾发布流程上。慢慢地，就断了。

中间还有一些文章，因为各种原因已经找不到了。说不心疼是假的，但也没办法。

为什么又重新开始

这次不一样。

我用上了 GitPress，写作体验完全不同——专注写内容，不用管部署。工具顺了手，坚持的可能性就大得多。

更重要的是，这次我想清楚了一件事：

简历上写”学习能力强”，谁都会写。但如果你能拿出一个博客，上面有你的项目、你的笔记、你解决问题的完整过程——那才是真的证据。

我不想等到毕业找工作的时候，才发现自己什么都没有留下。

从头开始，但不从零开始

旧博客里的大部分文章我不会搬过来。不是因为它们不好，而是因为它们代表的是”那个时候的我”——随手记、没想清楚、写到哪算哪。

这次重新开始，我想写得更认真一些。

但”从头开始”不意味着”从零开始”。过去折腾过的项目还在，过去踩过的坑也还记得。那些经验会变成新博客里的文章，只是这一次，我会写得更完整、更有条理。

一点不算鸡汤的感想

我越来越觉得，持续做一件小事，比偶尔做一件大事更有力量。

写博客就是这样的事。一篇文章可能没什么，几十篇、上百篇叠在一起，就是一个人成长的完整轨迹。

我不确定自己能坚持多久。但我知道，如果不开始，就永远不会有答案。

所以，从头开始吧。
